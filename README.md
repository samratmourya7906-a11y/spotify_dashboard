 🎵 Spotify Excel Dashboard

  About the Project

This project is an interactive Spotify Data Analysis Dashboard created using Microsoft Excel.

The project analyzes Spotify data and presents useful insights through "Pivot Tables, Pivot Charts, KPIs, and interactive visualizations".

   Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Data Visualization

 📊 Dashboard Features

* 🎵 Total Songs Analysis
* 🎤 Artist-wise Analysis
* 📅 Year-wise Analysis
* 📈 Music Trends
* 🔥 Popular Songs Analysis
* 📊 Interactive Charts & KPIs

 🎯 Objective

To transform raw Spotify data into meaningful insights using "Excel data analysis and visualization techniques".
